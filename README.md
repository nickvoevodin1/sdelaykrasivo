# «Сделай красиво» — сайт

Готовый статический сайт. Сборка не нужна: открывается двойным кликом, заливается на любой хостинг.

```
index.html            главная: боль → решение → услуги → калькулятор → процесс → цены → сравнение → FAQ → заявка
price.html            полный прейскурант
assets/css/style.css  все стили
assets/js/main.js     калькулятор, форма, анимации — и единственный блок настроек
```

## Настройка — одно место

Откройте `assets/js/main.js`, самый верх файла:

```js
var CONFIG = {
  telegram: "sdelaykrasivo",  // ваш ник без @
  endpoint: ""                // необязательно
};
```

- `telegram` — подставляется в ссылки в подвале и работает как канал заявок:
  при отправке формы откроется Telegram с уже написанным сообщением.
- `endpoint` — если хотите получать заявки на почту, заведите форму на
  [Formspree](https://formspree.io) или Getform и вставьте сюда адрес.
  Тогда форма отправится напрямую, без Telegram.

Больше менять ничего не нужно — сайт полностью заполнен.

## Публикация

- **Vercel** — перетащить папку на vercel.com/new.
- **Netlify Drop** — drag-and-drop на app.netlify.com/drop.
- **Свой хостинг** — залить содержимое папки в корень по FTP.

## Что где менять потом

- **Цены** — в двух местах: блок «Цены» в `index.html` и таблицы в `price.html`.
  В калькуляторе стоимость задаётся атрибутом `data-price` у строки.
- **Оценка штатного дизайнера** для сравнения в калькуляторе — переменная `STAFF`
  в `assets/js/main.js`, сейчас 120 000 ₽.
- **Плашка в первом экране** («Набираем первые 5 школ») — первая строка внутри
  `<header class="hero">` в `index.html`.
- **Цвета** — переменные в `:root` в начале `style.css`. Меняете пять значений —
  перекрашивается весь сайт.

## Дизайн

Светлый B2B-лендинг: индиго как единственный акцент, янтарный маркер для выделения,
крупная плотная типографика. Шрифты Manrope и Unbounded подключаются с Google Fonts.

Смысловой центр страницы — калькулятор: посетитель сам собирает свой месяц задач
и видит сумму рядом со стоимостью штатного дизайнера. Это и демонстрация прайса,
и главный аргумент в одном блоке.
