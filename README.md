# «Сделай красиво» — сайт

Статический сайт, без сборки. Открывается двойным кликом, заливается куда угодно.

## Структура

```
index.html            главная: боль → как работаем → что делаем → кейсы → цены → форма
price.html            полный прейскурант
assets/css/style.css  все стили
assets/js/main.js     появление секций + отправка формы (здесь же настройки)
assets/img/           сюда положить картинки кейсов
```

## Что нужно поменять перед публикацией

**1. Приём заявок.** Откройте `assets/js/main.js`, блок `CONFIG` в самом верху.

- `endpoint` — адрес формы (Formspree, Getform или свой скрипт). Заявки уйдут на почту.
- `telegram` — ваш ник без `@`. Работает как запасной вариант: если `endpoint` пустой,
  кнопка откроет Telegram с уже готовым текстом заявки.

Достаточно заполнить что-то одно.

**2. Кейсы.** В `index.html`, глава 4 — три заглушки с текстом «ЗАМЕНИТЬ НА РАБОТУ».
Положите картинки в `assets/img/` и замените блок:

```html
<div class="case__img">ЗАМЕНИТЬ НА РАБОТУ</div>
```

на

```html
<img class="case__img" src="assets/img/case-1.jpg" alt="Что делали для школы">
```

Без реальных работ страницу лучше не публиковать: пустой блок кейсов заметнее, чем его отсутствие.

**3. Плашка над заголовком.** В `index.html` в самом начале:

```html
<div class="stamp">Берём в работу первые 5 школ</div>
```

Здесь стоит формулировка под этап набора первых клиентов. Когда появится
проверяемая цифра, замените текст на неё.

## Публикация

- **Vercel** — перетащить папку на vercel.com/new, домен выдаётся сразу.
- **Netlify Drop** — то же самое, drag-and-drop.
- **Обычный хостинг** — залить содержимое папки в корень сайта по FTP.

## Дизайн

Идея — рабочая тетрадь: красное поле слева, номера глав на полях, синяя ручка как
акцент. Читается сверху вниз одной историей.

Шрифты: Literata (текст), IBM Plex Sans (интерфейс), IBM Plex Mono (цены и подписи).
Подключаются с Google Fonts, отдельная установка не нужна.

Цвета — в `:root` в начале `style.css`. Поменяв там пять значений, можно перекрасить
весь сайт.
